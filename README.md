# DOK-
An Extension of your computer, the DOK shows vital stats, slack pings, spotify updates, and much more. Connected to your PC via WIFI. also touchscreen! Uses custom PCB

I built/created this so that your PC/laptop could have a nice little companion. It sits next to your PC plugged in via USB-C for power (we will work on a battery soon!) and also runs Linux. Currently it only supports linking to Windows devices but we will have Mac support and maybe Linux in the future. It shows all the important stuff, managed via a custom PCB which includes power management, HDMI routing, and connection to the computer powering it all-the Orange Pi Zero 3. 


The screen we used is touchscreen and supports 10 point touch so the modern interface is nice. I built this because I was sick of having only one screen but didn't want to spend on a whole new monitor nor did I have the space for one. I wanted something a bit more filtered than your phone and bigger but tinier than an iPad. So I built DOK along with my friend, which filters out for the good stuff. It is a bit expensive but once RAM prices go down a bit I'm sure it'll get cheaper. I did want to include a local agent on here but the 4gb ram wasn't allowing for that so maybe that'll be a V2 update.
